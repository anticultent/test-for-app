# Setlist

A music-only mashup of TikTok's swipeable feed and Twitch's live co-streaming — React + Vite prototype.

## Local dev
```
npm install
npm run dev
```

## Deploy
This repo is Railway-ready as-is (railway.json included). Import it at railway.app, or hand the repo to Claude with Railway connected to deploy and get a live `*.up.railway.app` URL automatically.
